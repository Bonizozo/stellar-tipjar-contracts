================================================================================
CORE DATA STRUCTURES
================================================================================

RecoveryStatus enum:
  - Voting: Guardians voting on request
  - Locked: Timelock active, awaiting execution
  - Executed: Recovery completed
  - Rejected: Recovery failed

Guardian struct:
  - address: Address
  - weight: u32 (voting weight)
  - added_at: u64 (timestamp)
  - revocation_time: u64 (revocation effective time)

RecoveryRequest struct:
  - id: u64
  - creator: Address
  - new_owner: Address
  - status: RecoveryStatus
  - approval_count: u32
  - created_at: u64
  - executed_at: u64
  - timelock_end: u64

RecoveryAttempt struct:
  - request_id: u64
  - timestamp: u64

RecoveryConfig struct:
  - approval_threshold: u32 (66%)
  - timelock_delay: u64 (7 days = 604800 seconds)
  - guardian_revocation_delay: u64 (1 day = 86400 seconds)

================================================================================
SECURITY FEATURES
================================================================================

✅ Multi-Signature Voting
   - 66% guardian consensus required
   - Threshold automatically triggers locked state
   - Double-voting prevention

✅ Timelock Mechanism
   - 7-day delay before execution
   - Prevents immediate account takeover
   - Allows creator response time

✅ Guardian Revocation Delay
   - 1-day effective delay
   - Prevents accidental removal
   - Can be canceled during delay

✅ Authorization Controls
   - Creator-only: guardian management
   - Guardian-only: approvals
   - Time-based: execution

✅ Attempt Tracking
   - Historical record of all attempts
   - Enables rate limiting
   - Detects attack patterns

✅ Data Integrity
   - Single approval per guardian
   - Active guardian verification
   - State machine validation

PUBLIC API (8 Methods)
================================================================================

recovery_init(creator: Address)
  - Initialize recovery system for creator
  - Authorization: Any (permissionless)
  - Returns: None

recovery_add_guardian(creator: Address, guardian: Address, weight: u32)
  - Add trusted guardian
  - Authorization: Creator only
  - Emits: None
  - Returns: None

recovery_revoke_guardian(creator: Address, guardian: Address)
  - Initiate guardian revocation (1-day delay)
  - Authorization: Creator only
  - Emits: None
  - Returns: None

recovery_create_request(creator: Address, new_owner: Address)
  - Create recovery request
  - Authorization: Creator only
  - Emits: ("recovery", "request_created")
  - Returns: None

recovery_approve(request_id: u64)
  - Guardian approves recovery
  - Authorization: Guardian only
  - Emits: ("recovery", "approved"), ("recovery", "threshold_reached")
  - Returns: None

recovery_execute(request_id: u64) -> Address
  - Execute recovery after timelock
  - Authorization: Any (time-based)
  - Emits: ("recovery", "executed")
  - Returns: Address (new owner)

recovery_get_request(request_id: u64) -> RecoveryRequest
  - Query recovery request details
  - Authorization: Any (read-only)
  - Returns: RecoveryRequest struct

recovery_get_recent_attempts(creator: Address, since: u64) -> Vec<u64>
  - Query recent recovery attempts
  - Authorization: Any (read-only)
  - Returns: Vec of request IDs
